# Navigation Regression Checklist

Run these manually on radio after menu/navigation changes.

## Core return paths

1. `Tuning -> PID Controller -> Back`
Expected: returns to the `Tuning` screen (Steering, Drive Aids and Advanced groups) with icons.

2. `Setup -> Servos -> Servo 1 -> Back -> Back`
Expected:
- Back 1: `Servos` servo list
- Back 2: `Setup` screen with icons

3. `Setup -> ESC & Motors -> Drive -> Back`
Expected: `ESC & Motors` submenu with icons.

4. `Tools -> Profile Select -> Back`
Expected: `Tools` submenu with icons.
